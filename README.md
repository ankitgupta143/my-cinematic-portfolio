## 🌟 Overview

This is the personal portfolio of **Ankit Gupta**, a Full Stack Developer and Software Engineer. It merges scroll-driven cinematic video scrubbing, fluid GSAP micro-animations, 3D WebGL elements, interactive project showcases, and a responsive experience.

---

## 🚀 Key Features

* **🎥 Scroll-Driven Video Scrubbing**: Frame-accurate video playback synchronized directly to user scrolling speeds.
* **✨ Smooth GSAP Animations**: Scroll-triggered layouts, dynamic text reveals, and interactive motion.
* **🌐 3D Interactive Canvas**: Three.js and WebGL integration for interactive visual depth.
* **📱 Responsive & Modern UI**: Built with modern Tailwind CSS and optimized for mobile, tablet, and desktop viewports.
* **💼 Project Showcase**: Highlights full-stack applications, problem-solving journey, and technical achievements.
* **⚡ SEO & LLM Ready**: Dynamic metadata, structured search schemas, and dedicated LLM context files (`/llms.txt`).

---

## 🛠️ Tech Stack

* **Framework**: Next.js 15 (App Router)
* **Frontend Library**: React 19
* **Styling**: Tailwind CSS 4, Vanilla CSS
* **Animation & Motion**: GSAP 3, ScrollTrigger, Framer Motion, Lenis Smooth Scroll
* **3D & Graphics**: Three.js, React Three Fiber, WebGL
* **Backend & Database**: Next.js API Routes, Node.js, Supabase
* **Deployment**: Vercel

## 💻 Getting Started Locally

### 1. Clone the repository
```bash
git clone https://github.com/ankitgupta143/my-cinematic-portfolio.git
cd my-cinematic-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Setup environment variables
Copy `.env.example` to `.env.local` and add your credentials:
```bash
cp .env.example .env.local
```

### 4. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
